# 播放与弹幕

## Windows 播放窗口

在视频或直播播放器顶部的“播放窗口”菜单选择“弹出为独立小窗”。小窗接管播放后，主窗口暂停原内容，可继续浏览或打开其他视频。点播保留分 P、集数和进度，离线视频也可弹出。打开期间主窗口继续播放，小窗准备好画面后接管声音；加载失败可点击重试。

| 操作 | 方法 |
| --- | --- |
| 置顶、移动、缩放 | 默认置顶；顶部图钉可取消置顶，拖动画面移动，拖动边缘缩放 |
| 全屏与退出 | 使用右上角按钮，`Esc` 退出全屏 |
| 排列多个窗口 | 窗口菜单选择网格或层叠排列，目标是鼠标所在显示器的工作区 |
| 恢复窗口位置 | 关闭后重新使用同一空闲窗口位置，会恢复上次的位置和大小，并调整超出显示器的部分 |
| 只听一个窗口 | 窗口菜单选择“只听这个窗口”；新小窗开始播放时默认接管声音 |
| 多窗口同时发声 | 分别调节各窗口音量 |
| 直播卡顿或加载失败 | 在更多菜单打开“播放线路”，切换线路；面板显示各来源的画质、格式和编码 |

视频和直播底部的音量按钮可打开竖向滑块，再次点击或点击外部关闭。滚轮、`↑`、`↓` 调节音量，`M` 切换静音；滑块底部也有静音按钮。音量以 0～100% 显示，调节音量会取消当前窗口的静音。

小窗使用打开时的账号和播放设置，窗口内修改不覆盖主窗口配置。主窗口换账号或改设置后，重新打开小窗使用新配置。离线小窗关闭时回写进度；退出主窗口会关闭所有播放小窗并释放资源。Android 系统画中画使用独立实现。

## 视频缓存

在“设置 → 播放设置 → 视频缓存策略”选择策略，下次加载点播媒体时生效。默认使用“均衡”。“缓冲大小”是基准容量，设置页同时显示当前策略实际的前向、后向上限。

| 策略 | 前向容量 | 后向容量 | 补读时机 |
| --- | --- | --- | --- |
| 省内存 | 基准 × 1 | 基准 × 1 | 剩余预读目标的一半时 |
| 均衡 | 基准 × 4 | 基准 × 1 | 剩余预读目标的 75% 时 |
| 流畅优先 | 基准 × 8 | 基准 × 1 | 剩余预读目标的 87.5% 时 |

默认基准 4 MiB，均衡策略的前向／后向上限为 16／4 MiB。实际预读达到时长目标或容量上限之一就停止；高码率内容可能先达到容量上限。Windows 同时按剩余时长和字节量提前补读，Android 使用时长阈值。分离音视频分别受这些上限约束，解码及画面纹理另占内存。

短距离回退会复用仍保留的缓存；跳到未缓存或已经淘汰的位置时重新读取。缓存条表示当前缓存边界，跳转后可以回退。倍速调整会换算预读媒体时长，容量上限保持不变。直播沿用独立缓存策略，不受此选项影响。

## 弹幕合并与帧率

在播放设置的“弹幕与字幕”或播放器弹幕面板中调整。

| 设置 | 默认值与效果 | 生效时机 |
| --- | --- | --- |
| 弹幕合并 | 默认关闭；合并 20 秒内相同或相似的内容，保留首条原文并显示重复数量 | 立即生效，规则处理期间相关弹幕可能暂时隐藏 |
| 合并弹幕字号放大 | 默认开启；重复数量超过 7 后放大，最高两倍；放大速度默认 7，数值越小增长越快 | 立即生效 |
| 弹幕轨道间距 | 默认 1.6 倍，可选 1～3 倍，步进 0.1；越小可容纳轨道越多 | 播放器内调整立即生效，全局设置用于后续打开的播放页面 |
| Android 弹幕帧率 | 默认跟随屏幕，也可选 60、90、120 FPS；旧 30 FPS 设置按跟随屏幕生效 | 立即生效，同步时可能短暂波动 |
| Windows 弹幕帧率 | 自动跟随屏幕，历史保存的档位不再影响 Windows | 随屏幕与窗口状态调整 |

合并窗口从首条开始，后续重复内容不会延长窗口。匹配忽略大小写、空白和常见标点等差异，较长文字允许少量差异；数字或否定词不同的内容保持独立。自己发送的弹幕、不同显示模式和特殊弹幕保持独立，屏蔽先于合并。在线弹幕按加载分段合并，跨分段可能保留重复内容；本地文件按全文件时间顺序合并。

密集场景下部分弹幕可能不显示，或重复内容仍单独显示。候选优先保留自己发送的弹幕，其余按服务端权重排序，同权重保持来源次序；已显示的轨迹不会被后到弹幕抢占。放大的弹幕按实际高度占多条轨道，轨道数量也受字号、播放区域高度和显示区域比例影响。

弹幕目标帧率用于控制绘制开销，实际效果取决于屏幕、设备负载和视频。整体画面刷新频率可能高于所选弹幕帧率，设备也可能选择更高的屏幕刷新档位。

## 空降助手

在“设置 → 播放 → 空降助手”开启功能、选择片段分类行为，也可修改服务地址。

- 自动处理和处理一次按片段动作跳过或静音；整片标记和精彩时刻只展示。
- “手动跳过”显示提示，由用户决定，适用于不希望自动静音的惊吓片段。
- 新安装默认自动处理惊吓片段；升级保留原选择，新增分类默认禁用，也不会重置已有分类行为和颜色。
- 静音不修改系统音量或保存的音量。重叠静音片段全部结束、跳出片段、结束监听或换媒体后解除；用户自己开启的静音和期间调整的音量仍保留。
