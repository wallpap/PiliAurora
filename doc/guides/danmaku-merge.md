# 弹幕合并与帧率设置

在播放设置的「弹幕与字幕」中调整，也可从视频播放器的弹幕设置面板进入。弹幕合并默认关闭；合并开关和字号放大参数修改立即生效。来源重算期间受影响弹幕暂时隐藏，当前规则处理完成后恢复。帧率选择适用于 Android，Windows 自动跟随屏幕。

## 弹幕帧率

### Windows

点播和直播弹幕自动跟随屏幕刷新节奏。设置页和播放器面板已移除帧率选择，历史保存的帧率档位不影响 Windows。实际更新与呈现受屏幕刷新率、窗口可见状态和设备负载影响。

### Android

默认「跟随屏幕」，也可选择 60、90、120 FPS 作为弹幕目标帧率。旧版保存的 30 FPS 设置自动按「跟随屏幕」生效。修改时保留当前弹幕与显示实例，同步期间可能短暂波动。目标档位用于安排弹幕更新节奏，可降低绘制开销；实际弹幕更新仍受屏幕刷新率和设备负载影响。视频帧率由媒体与播放器决定，视频与弹幕的帧时序共同影响整体画面刷新频率，可能高于弹幕目标帧率。屏幕实际刷新率还取决于设备和系统可用的刷新档位，可能向上选择更高档位。

目标帧率达到屏幕刷新率时直接跟随 vsync，并为标称同频的刷新率读数保留 0.5 Hz 容差，例如 120 与 120.000007 Hz。较低档位按承载目标时间的屏幕槽位提前半个周期请求下一帧，并扣除本次弹幕更新已花费的时间，避免临近 vsync 才请求而错过该帧。视频采样连续六个间隔稳定、且与弹幕目标周期可按整数比例匹配时，在下一次调度中就近校准相位。采样到来时保留已经安排的唤醒，减少定时器重建。

视频帧间隔不稳定或与弹幕目标周期无法匹配时，退回独立目标帧率调度；重新获得稳定且匹配的采样后恢复同步。退化期间，视频与弹幕合计刷新的频率可能高于弹幕目标帧率。调度以减少弹幕绘制与额外唤醒为目标，模拟中的刷新次数和唤醒次数用于横向比较调度开销，设备耗电量另行测量。

弹幕使用所在视图的屏幕刷新率作为更新上限，并以播放器当前实际生效的显示同步状态决定是否尝试合帧。显示同步未生效或状态尚未确认时，使用独立目标帧率调度；刷新率信息不可用时保留所选目标节奏。视频同步设置在播放器初始化时应用，弹幕会随播放器实际状态变化切换调度。

## 密集弹幕的显示

点播弹幕密集时，来源缓存和显示候选受容量限制，部分弹幕可能不显示。候选优先保留自己发送的弹幕，其余按服务端权重排序；权重相同时保持来源次序。已建立的弹幕轨迹不会被后到的高权重弹幕抢占。

## 合并规则

相同或相似的弹幕在 20 秒内合并，显示首条原文及重复数量。窗口从首条弹幕开始计算，后续重复内容不会延长窗口。在线弹幕在每个加载分段内处理，本地弹幕文件按稳定时间顺序分批处理并保持全文件合并锚点；在线分段交界处保持独立。

匹配会统一全角英文、大小写、空白和常见标点，并归一连续重复的非数字字符。长度不足 8 个字符或超过 200 个字符的内容进行规范化后的相同匹配；8～200 个字符的内容允许少量编辑差异，数字和否定词差异保持独立。普通池（pool=0）与互动池（pool=3）的普通文字弹幕参与合并，包括重复的评分数字；不同模式、自己发送的弹幕、字幕池、特殊池与高级弹幕保持独立。屏蔽规则先于合并执行。

匹配状态最多保留 2048 个合并组，每条弹幕最多检查 64 个相似候选；高密度或大量不同内容下，部分重复弹幕可能保持独立。在线分段和本地文件的合并通过后台 isolate 执行，页面退出后的结果会被丢弃。

## 字号放大

「合并弹幕字号放大」默认开启，可独立关闭。放大阈值默认为 7，重复数量超过阈值时按对数增长；放大速度默认为对数底数 7，数值越小增长越快。字号保持至少原大小，最高两倍。放大的弹幕按实际高度占用多条轨道，普通弹幕沿用基础轨道间距。

## 轨道间距

「弹幕轨道间距」可在 1–3 倍之间调整，步进 0.1，默认 1.6。数值越小，同屏可容纳的轨道越多；轨道高度至少容纳普通文字与描边，轨道数量随字号、播放区域高度和显示区域比例变化。播放器面板中调整立即生效，全局设置用于后续打开的播放页面。Android 和 Windows 均按弹幕实际高度检查相邻轨道占用。

功能参考 [PiliNara 的增强合并弹幕说明](https://github.com/Starfallan/PiliNara#改动说明未来计划)。本项目使用有界编辑距离匹配，无新增拼音依赖。
