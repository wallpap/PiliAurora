# 账号与设置备份

## 本机数据

账号、设置和缓存保存在应用支持目录下的 Hive 文件中，当前未启用应用层加密。Windows 默认目录为 `%APPDATA%\wallpap\PiliAurora\hive`。WebDAV 密码随普通设置保存。

## 导入与导出

“关于”页分别提供“导入/导出登录信息”和“导入/导出设置”。可导出为 JSON 文件或复制到剪贴板；导入支持文件、剪贴板或手动输入 JSON。

登录信息备份包含 Cookie、Token 等凭证。设置备份包含 `setting`、`video` 两个分区，不包含登录账号；已配置的 WebDAV 用户名与密码会随设置导出。两类备份都是未加密的 JSON，应按凭证保管，避免直接上传到 issue 或公开分享。

导入设置会替换两个分区中的内容，并删除备份中未列出的键。导入前可先导出现有设置；缺少任一分区的备份会在写入前被拒绝。

## WebDAV 备份

WebDAV 上传和恢复使用相同的设置 JSON，恢复时不需要备份密码。服务地址使用 HTTPS；仅访问 `127.0.0.1` 或 `::1` 的本机 HTTP 服务可在每次确认后连接。

设置备份与 WebDAV 传输由 `lib/services/settings/` 管理；账号读写见 `lib/utils/accounts.dart`。
