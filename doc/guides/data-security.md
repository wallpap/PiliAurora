# 账号与设置备份

## 导入与导出

备份账号和设置需要分别操作，均不需要备份密码。

1. 打开“关于”，选择“导入/导出登录信息”或“导入/导出设置”。
2. 备份时，导出为 JSON 文件或复制到剪贴板。
3. 恢复时，在目标设备的同一入口导入文件、读取剪贴板或手动输入 JSON。

恢复设置前先导出现有设置。导入会替换备份包含的设置分区，具体范围见下表。

| 备份类型 | 内容与加密范围 |
| --- | --- |
| 登录信息 | 包含账号 Cookie、访问 Token、刷新 Token 和账号用途；Cookie、Token 字段加密，账号标识和用途保持可读。 |
| 设置 | 包含 `setting`、`video` 两个分区，不包含登录账号；仅 WebDAV 密码字段加密，服务地址、用户名和其他设置保持可读。 |

导入设置会替换两个分区中的内容，并删除备份中未列出的键。备份缺少分区或 WebDAV 密文损坏时，应用会在写入前报错。导入过程中若写入失败，两个分区可能只恢复部分内容。

## 版本与跨设备兼容

当前版本可导入旧明文备份，也可直接恢复新密文备份。旧明文凭证导入后按新格式保存。新密文需要支持该格式的应用版本读取，降级前应确认旧版本的数据兼容性。

跨设备恢复时，在目标设备导入备份即可，无需额外保存密码。备份包含登录凭证和个人设置，请妥善保管，避免公开分享或上传到 issue。

备份中的密文损坏或版本不受支持时，导入会报错。

## WebDAV 备份

WebDAV 上传和恢复使用相同的设置 JSON，连接时使用配置的用户名和密码。服务地址使用 HTTPS；仅访问 `127.0.0.1` 或 `::1` 的本机 HTTP 服务可在每次确认后连接。本机 HTTP 连接以明文传输认证信息和可读设置，请确认服务可信。

## 本机数据

账号、设置和缓存保存在应用支持目录下的 Hive 文件中。Windows 默认目录为 `%APPDATA%\wallpap\PiliAurora\hive`。

账号 Cookie、访问 Token、刷新 Token 和 WebDAV 密码加密保存，普通设置、账号标识和缓存保持原格式。升级后会自动迁移本机旧明文凭证。此前复制或导出的备份文件保持原样。

实现说明见[架构概览](../development/architecture.md#凭证存储与备份)，验证范围见[构建与测试](../development/build-and-test.md)。
