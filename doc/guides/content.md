# 内容过滤与互动

## 黑名单屏蔽

进入“设置 → 账号与隐私 → 增强黑名单屏蔽”。主开关默认开启，按主账号黑名单过滤作者；下方“检查合作视频作者”也默认开启，列表明确标识的合作视频中，任一作者被拉黑即屏蔽。关闭合作作者检查后仍过滤主投稿者。切换开关后刷新信息流生效。

| 入口 | 处理方式 |
| --- | --- |
| 首页、热门、搜索中的视频／专栏／直播／用户、动态与话题、直播推荐与分区 | 过滤后在可分页的列表中沿原来源补位 |
| 排行、每周必看、详情页相关视频 | 过滤后保持原顺序及列表范围 |
| 收藏、历史、稍后再看、直接打开详情 | 沿用原有行为 |

分页补位每次最多读取五页，遇到终点、空页或失败时停止。首页按视口补足内容，连续五页无有效增长时等待刷新；分页失败会保留内容，点击页尾“加载失败，点击重试”继续。

首页普通卡片先显示，需要检查作者的合作视频先显示占位，通过后显示，命中屏蔽则移除并补位。检查会增加流量和等待时间，可单独关闭。作者信息会被复用，拉黑或解除后按当前名单判断；查询失败时按已知作者过滤，黑名单同步失败时沿用当前账号缓存。

未按预期屏蔽时，先确认当前主账号及黑名单，刷新列表，再核对上方适用范围。

## 评论等级过滤

在“设置 → 内容与互动 → 内容过滤 → 最低评论用户等级”选择不屏蔽，或 Lv1～Lv6 及以上。默认不屏蔽，修改后刷新评论区生效。

适用于视频、番剧、动态和文章评论，以及置顶、楼中楼预览、回复和对话列表。缺少用户资料的评论会保留，评论详情中的原评论也保留作上下文；回复总数来自服务端，可能大于过滤后的条数。

过滤使用响应中的等级，不额外查询资料。每次加载最多自动补取五页，暂未找到符合条件的评论时，可点“继续加载”。

## 弹幕点赞

登录后打开弹幕操作浮层或弹幕列表，应用先查询当前账号点赞状态。查询期间显示占位，完成后显示状态与数量。失败时点击重试只重新查询；状态确认后，点击点赞图标才会点赞或取消。

## 评论长按菜单

长按主评论或楼中楼可复制、保存评论。删除、举报和置顶入口按账号与评论归属显示。

登录后，其他用户评论菜单中的“拉黑用户”可将其加入黑名单，确认后会提示结果；自己的评论没有该入口。可在黑名单管理中解除。

## 表情包管理

打开评论输入框的表情面板，点击设置按钮进入管理页。

- “已添加”页点击右侧按钮移除；“未添加”页点击右侧按钮添加。
- “未添加”可按全部、装扮商城、会员专属、包月充电筛选，搜索框按名称筛选当前列表。
- 点击名称或封面预览，点击单个表情放大。加载失败可重试。
- 右上角可刷新或在浏览器打开，返回输入面板会重新加载列表。

Android 和 Windows 共用这些页面。表情包可用范围及添加权限取决于当前账号和 B 站接口。
