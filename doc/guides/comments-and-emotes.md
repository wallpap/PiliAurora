# 弹幕、评论与表情包

Android 和 Windows 共用评论与表情包页面。

## 视频弹幕点赞

登录后，打开弹幕操作浮层或“弹幕列表”，应用会查询当前账号的点赞状态。查询期间，点赞位置显示加载占位，完成后再显示已点赞或未点赞图标及数量。

查询失败时，该位置显示重试按钮。重试只重新查询状态；状态确认后，点击点赞图标才会点赞或取消点赞。

## 评论等级过滤

在“设置 → 内容与互动 → 内容过滤 → 最低评论用户等级”中，可选择不屏蔽，或仅显示 Lv1～Lv6 及以上用户的评论。默认不屏蔽，修改后刷新评论区生效。

等级过滤适用于视频、番剧、动态和文章评论，以及置顶评论、楼中楼预览、回复列表和对话列表。缺少用户资料的评论保留；评论详情的原评论保留作为上下文。回复总数沿用服务端统计，可能大于过滤后的条数。

过滤使用响应内的用户等级，不额外查询用户资料。每次加载最多自动补取五页；暂未找到符合条件的评论时，可点击“继续加载”查看后续页面。

## 评论长按菜单

长按主评论或楼中楼评论可打开操作菜单，支持复制、保存评论等操作。删除、举报和置顶入口会根据账号与评论归属显示。

登录后，其他用户的评论菜单中会显示“拉黑用户”。点击并确认后将该用户加入黑名单，操作结果会以提示反馈。自己的评论不显示该入口；以后可在黑名单管理中解除拉黑。

## 表情包管理

打开评论输入框中的表情面板，点击设置按钮进入“表情包管理”。

- “已添加”显示当前表情包，点击右侧移除按钮可移除。
- “未添加”显示可添加的表情包，可按全部表情、装扮商城、会员专属、包月充电筛选，再点击右侧添加按钮。
- 搜索框按表情包名称筛选当前列表；分类标签仅显示在“未添加”页签。
- 点击表情包名称或封面进入内容预览，点击单个表情可放大查看。加载失败时可点击提示重试。

管理页右上角提供刷新与浏览器入口。返回输入面板后会重新加载表情包列表。表情包可用范围及添加权限取决于当前账号和 B 站接口响应。
