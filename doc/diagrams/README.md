# 播放器与弹幕架构图

以下图表从职责、所有权和协议说明播放器、弹幕与帧调度。节点表示抽象边界，图下表格补充交换的信息、生效条件与限制；实现映射见各图文末链接。

HTML 文件自带 SVG 与样式，可直接在浏览器查看。画布为 1920×1280，面向 1920px 及以上宽度的大屏；四张图之间可通过顶部导航切换。

- [播放职责与生命周期](player-architecture.html)：业务计划、控制权、规范状态、读模型和原生资源的归属，以及异步结果与释放屏障。
- [弹幕数据与显示时间](danmaku-architecture.html)：有界准备、范围窗口、直播候选、两种时间基准和显示实例的资源边界。
- [帧节奏与出画证据](presentation-scheduler-architecture.html)：构建身份、平台节奏、采样准入、纹理消费及失效恢复条件。
- [加载与帧更新时序](playback-danmaku-sequence.html)：加载就绪、独立时钟和框架帧的协作，以及旧采样失效与恢复条件。

媒体位置用于内容进度求值，框架帧目标用于更新调度，纹理消费事实用于首帧过渡和播放健康判断。构建工具核对定制引擎身份，应用启动时校验配置与摘要格式。
