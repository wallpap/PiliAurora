# 领域词汇表

这里解释项目中容易混淆的业务和工程术语。具体行为仍以源码和测试为准。

## 产品与平台

| 术语 | 含义 |
| --- | --- |
| PiliAurora | 本仓库维护的 Bilibili 第三方客户端，与 Bilibili 官方无隶属关系。 |
| 上游 | 主要指 PiliPlus 2.1.5 及其历史来源。上游更新不会自动同步到本仓库。 |
| 移动端 | 本项目的 Android 目标平台。代码中的 `PlatformUtils.isMobile` 也可能代表一组平台。 |
| 桌面端 | 本项目的 Windows 目标平台，发布目标为 Windows x64。 |
| 页面 | 可导航的 Flutter 界面，通常位于 `lib/pages/<领域>/`。 |
| 领域 | 围绕一个用户任务组织的页面、接口、模型、服务和测试。 |

## Bilibili 资源

| 术语 | 含义 |
| --- | --- |
| mid | Bilibili 用户标识。 |
| aid / BV 号 | 视频的两种标识形式。模型可能同时保存 `aid` 和 `bvid`，调用时应检查所需字段是否存在。 |
| CID | 视频分 P 或媒体内容标识；播放地址和视频弹幕请求常用到它。 |
| UGC | 用户生成内容。 |
| PGC | 专业或版权内容，如番剧和课程。其分集与播放流程可能不同于 UGC。 |
| 动态 | Bilibili 社区动态，包括发布、转发和互动。 |
| 收藏夹 | 用户管理已收藏的视频、文章、番剧等资源的功能。 |
| 稍后再看 | 用户保存待观看内容的资源集合。 |

## 媒体与互动

| 术语 | 含义 |
| --- | --- |
| 弹幕 | 随视频时间或直播过程显示的评论。视频弹幕与直播弹幕使用不同的传输生命周期。 |
| 直播包 | 直播实时传输的原始数据单元，解包后包含一条或多条消息。 |
| 播放器后端 | 负责媒体解码、时钟和输出的实现；项目主要通过 media_kit、mpv 和平台库提供。 |
| 硬件解码 | 使用设备或系统解码器的播放路径。出错时要检查解码回退过程。 |
| 回退链路 | 当前解码器或播放配置失败后，继续尝试其他候选路径的策略。执行顺序以代码为准。 |

## 工程术语

| 术语 | 含义 |
| --- | --- |
| API 模块 | `lib/http/` 中按业务领域拆分的请求代码。 |
| 远端模型 | `lib/models/remote/` 中映射 Bilibili 或其他远端响应的数据结构。 |
| 服务 | 跨页面或长生命周期能力，例如账号、下载、直播流、诊断和音频。 |
| 持久化 | 将设置、账号、历史或缓存元数据保存到本地存储或文件系统。 |
| 诊断记录 | 播放器、网络、下载、直播、启动和进程状态的结构化观测数据。 |
| 生成代码 | protobuf、JNI 等工具生成的代码。应修改源定义或脚本，再按流程生成。 |
| 已确认 / 工作模型 / 待实测 | 文档中的事实级别：源码可直接确认、用于导航的架构概括、需要在指定环境验证。 |

## 排障时要分清

- 播放故障可能出在地址解析、网络、解码器初始化、解码中断或渲染窗口。
- 缓存包括图片缓存、HTTP/响应缓存、播放器与渲染缓存，以及下载文件。
- 登录状态包括本地账号记录、当前账号、Cookie/Token 有效性和服务端会话。
- 直播容量涉及聊天历史、未读积压、消息渲染压力和连接生命周期。
