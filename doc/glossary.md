# 领域词汇表

本文档记录项目中容易产生歧义的业务和工程术语，不替代代码契约。

## 产品与平台

| 术语 | 含义 |
| --- | --- |
| PiliAurora | 本仓库维护的 Bilibili 第三方客户端，不隶属 Bilibili 官方。 |
| 上游 | 主要指 PiliPlus 2.1.5 及其历史来源；上游继续变化不等于本仓库自动同步。 |
| 移动端 | 当前项目目标中的 Android；代码中也可能使用 `PlatformUtils.isMobile` 表达平台集合。 |
| 桌面端 | 当前项目目标中的 Windows，发布目标为 Windows x64。 |
| 页面 | 可导航的 Flutter 界面，通常位于 `lib/pages/<领域>/`。 |
| 领域 | 围绕一个用户任务组织的页面、接口、模型、服务和测试集合。 |

## Bilibili 资源

| 术语 | 含义 |
| --- | --- |
| mid | Bilibili 用户标识。 |
| aid / BV 号 | 视频的两种标识形式；模型可能同时持有 `aid` 和 `bvid`，不可假设始终都有值。 |
| CID | 视频分 P/媒体内容标识；播放地址和视频弹幕经常需要它。 |
| UGC | 用户生成内容。 |
| PGC | 专业/版权内容，如番剧、课程等；其分集和播放链路可能不同于 UGC。 |
| 动态 | Bilibili 社区动态流、发布、转发和互动功能。 |
| 收藏夹 | 用户管理收藏视频、文章、番剧等资源的功能。 |
| 稍后再看 | 用户保存待观看内容的资源集合。 |

## 媒体与互动

| 术语 | 含义 |
| --- | --- |
| 弹幕 | 随视频时间或直播过程叠加显示的评论。视频弹幕和直播弹幕不应视为同一传输生命周期。 |
| 直播包 | 直播实时传输中承载多个消息的原始数据单元，需解包后处理。 |
| 播放器后端 | 负责媒体解码、时钟和输出的实现，项目主要通过 media_kit/mpv 及平台库提供。 |
| 硬件解码 | 使用设备或系统解码器的播放路径。失败时应检查回退链路，而非只观察页面错误。 |
| 回退链路 | 当前候选解码器/播放配置失败后，继续尝试其他候选路径的策略。具体顺序以代码为准。 |

## 工程术语

| 术语 | 含义 |
| --- | --- |
| API 模块 | `lib/http/` 下按业务域拆分的请求封装。 |
| 远端模型 | `lib/models/remote/` 下映射 Bilibili 或其他远端响应的模型。 |
| 服务 | 跨页面或长生命周期能力，如账号、下载、直播流、诊断和音频。 |
| 持久化 | 将设置、账号、历史、缓存元数据等写入本地存储或文件系统。 |
| 诊断记录 | 为播放器、网络、下载、直播、启动和进程状态保存的结构化观测数据。 |
| 生成代码 | protobuf、JNI 等工具产出的代码；应修改源定义/脚本后重新生成，不直接手改产物。 |
| 已确认 / 工作模型 / 待实测 | 文档中的事实等级：代码直接可见、用于导航的架构概括、必须在特定环境验证。 |

## 排障时必须区分

- 播放失败：地址解析、网络、解码器初始化、解码中断、渲染/窗口错误。
- 缓存：图片缓存、HTTP/响应缓存、播放器/渲染缓存和下载文件。
- 登录状态：本地账号记录、当前选中账号、Cookie/Token 有效性和服务端会话。
- 直播容量：聊天历史、未读积压、消息渲染压力和连接生命周期。
