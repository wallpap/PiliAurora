# 登录凭证与密码加密

本地账号 Box 中的 Cookie、accessKey、refresh 使用 Hive 自带的 AES-256 加密。WebDAV 密码独立存放在同样加密的 `credentials` Box 中；普通设置、用户资料和缓存维持原存储方式。随机密钥通过 `flutter_secure_storage` 交给系统安全存储保管，不写入配置、日志或导出文件。Android 禁用安全存储出错时自动重置。

首次升级读取旧账号 Box，写入临时加密副本并重新打开校验，成功后才删除旧明文文件。旧设置中的 WebDAV 密码先写入加密存储并刷盘，再从设置删除并压缩 Hive 日志。密钥不可用或解密失败时不自动清空或覆盖数据。Windows 播放子窗口通过内存快照读取账号及密码，不另写磁盘副本。

登录信息的文件和剪贴板导出使用密码加密 JSON。普通设置导出与 WebDAV 设置备份继续使用可读 JSON，无需设置备份密码；若包含非空 WebDAV 密码，只加密该字段，并要求设置和确认备份密码。所有原有字段仍可恢复。旧版明文登录信息与设置备份继续支持导入，旧明文 WebDAV 密码会写入加密存储。

可移植备份的敏感内容采用 PBKDF2-HMAC-SHA256（210000 次、随机 16 字节盐）派生 256 位密钥，使用 AES-GCM（随机 12 字节 nonce、128 位认证标签）。备份密码至少 8 个字符，不保存到应用；恢复时需输入原密码，验证失败不会应用导入内容。

兼容范围为新版读取旧数据。旧程序无法读取加密账号文件或新的加密密码字段。跨设备迁移使用导出文件；单独复制本地 Hive 目录无法代替系统密钥。已有历史明文备份不会自动改写，忘记备份密码无法恢复加密内容。

Hive 值加密不隐藏键名（可能含 UID）、文件名或大小。
