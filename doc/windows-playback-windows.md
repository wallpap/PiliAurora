# Windows 播放窗口

视频和直播播放器顶部的「播放窗口」菜单提供「弹出为独立小窗」。小窗开始播放后，主窗口暂停原内容，可以继续浏览或打开其他视频、直播间。重复此操作可同时观看多个内容；点播保留当前分 P、番剧集数和播放进度，离线视频也可弹出。

小窗默认置顶，可以通过播放器顶部的图钉取消置顶，通过画面拖动窗口、通过边缘调整大小。关闭小窗后，再打开同一空闲窗口位置会恢复其上次的位置和大小；超出当前显示器工作区的位置会自动调整。播放器顶部返回按钮和窗口菜单的「关闭播放窗口」均可关闭小窗。

「网格排列播放窗口」和「层叠排列播放窗口」将所有小窗排列到鼠标所在显示器的工作区，主窗口保持原位置。

视频和直播播放器底部的音量按钮打开滑块，可调节音量和切换静音。音量上限沿用播放器设置，默认支持 200%；`↑`、`↓` 调节音量，`M` 切换静音。滑块与快捷键保持同步。调节音量会取消当前窗口的静音。

新小窗开始播放时接管声音，其余小窗和主窗口静音。任意播放器的窗口菜单中选择「只听这个窗口」可切换声音来源；也可分别调节各个窗口的音量，使多个窗口同时发声。

小窗使用打开时的账号和播放设置，窗口内的设置变更不会覆盖主窗口配置。更换主窗口账号或设置后，重新打开小窗即可使用新配置。离线小窗关闭时会将观看进度写回主窗口。主窗口退出后，已有小窗继续播放；窗口排列、位置保存和离线进度回写由主窗口管理，需要保持主窗口运行。

Windows 的独立窗口功能与 Android 系统画中画分别实现。真实直播、音频输出和不同 GPU、显示器组合的表现需要在对应设备上验证。
