# PiliAurora v1.6.7

## 评论与浏览

- 新增最低评论用户等级设置，可按 Lv1～Lv6 过滤评论及回复。默认不屏蔽，修改后刷新评论区生效。设置位置和适用范围见[弹幕、评论与表情包](../guides/comments-and-emotes.md#评论等级过滤)。
- 首页推荐中的合作视频卡片在作者核验通过后逐张显示，减少列表整体重建。
- 消息提醒设置在选项加载完成后再弹出选择框。
- 统一部分操作菜单的内圆角和悬停效果。

## 播放与弹幕

- 修复 Windows 超分切换时渲染器重建与媒体加载的衔接。切换时短暂重载媒体，点播恢复播放位置并保留暂停或播放状态。
- Windows 进入全屏前先更新播放器布局，减少过渡闪动。
- Windows 播放库改用上游标准 libmpv 包。
- 移除 Android 的 30 FPS 弹幕档位，旧设置按“跟随屏幕”生效；仍可选择 60、90、120 FPS。Windows 弹幕继续跟随屏幕。

## 下载安装

Android 提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 安装包；Windows 提供 x64 安装程序和便携包。

Windows 安装版更新时，将安装程序指向原安装目录。便携版更新时，将 ZIP 完整解压到新目录，再启动其中的 `PiliAurora.exe`。账号和设置保存在 Windows 用户数据目录。
