# PiliAurora 2.0.1

本次更新统一 Android 和 Windows 的构建版本，改进发布构建流程。

## 版本与更新

- 两个平台统一显示 `2.0.1+构建号`，Android 构建不再把提交哈希附加到版本名；提交信息仍保留在构建元数据中。
- 更新检查继续按正式版本比较，跳过草稿和预发布版本；仅构建号变化不会重复提示。下载时按设备架构选择 Android APK，Windows 提供安装版和便携版。
- 发布构建使用相同版本命名附件，并在发布页附上对应的版本说明。

## 下载与安装

在本发布页选择 Android 对应架构的 APK，或 Windows x64 的 `setup.exe` 安装版、`portable.zip` 便携版。Windows 安装版请先退出主窗口和独立播放窗口；便携版请完整解压到新目录。更新后可在“关于”页面核对版本。

如从 1.6.x 升级，播放、缓存、图片及账号状态等主要变化见 [2.0.0 更新说明](https://github.com/wallpap/PiliAurora/blob/main/doc/releases/v2.0.0.md)。

## 验证范围

本次发布构建按需跳过主机 CI 测试和 Windows 覆盖安装测试，保留依赖及预编译产物校验。目标设备上的画面、声音和性能仍需分别验收，详见[默认构建与策略](https://github.com/wallpap/PiliAurora/blob/main/doc/development/build-defaults.md)。
