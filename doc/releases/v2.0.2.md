# PiliAurora 2.0.2

## 迁移通知

后续版本将在 [PiliAuroraNext](https://github.com/wallpap/PiliAuroraNext) 继续维护。本仓库计划只读归档，保留现有源码和历史发布。请前往新仓库关注更新、提交问题和参与开发。

新仓库的版本将使用新的应用包名，安装后可能需要重新登录，或导入设置与账号信息。迁移前建议先[导出账号与设置备份](https://github.com/wallpap/PiliAurora/blob/main/doc/guides/data-security.md)。

2.0.2 是本仓库的迁移通知版本，Android 和 Windows 安装包仍在本发布页提供。

## 本次更新

- 改进系统媒体按键对当前播放窗口的控制，修复连续快进、快退及暂停时的进度交接。
- 修复评论过滤后分页提前结束、置顶评论子回复过滤，以及动态关注作者分页合并的问题。
- 修复部分播放源切换 CDN 时的鉴权信息丢失，并调整直播全屏、字幕位置和图文排版。

## 下载与安装

Android 请按设备架构选择 `arm64-v8a.apk`、`armeabi-v7a.apk` 或 `x86_64.apk`。Windows x64 提供 `setup.exe` 安装版和 `portable.zip` 便携版。更新前请退出主窗口和独立播放窗口；便携版请完整解压到新目录。更新后可在“关于”页面核对 `2.0.2+构建号`。

后续版本的下载和安装方式请以新仓库的说明为准。

## 验证范围

本次发布工作流启用主机 CI 测试和 Windows 覆盖安装测试，并校验依赖及预编译产物。目标设备上的画面、声音和性能仍需分别验收，详见[默认构建与策略](https://github.com/wallpap/PiliAurora/blob/main/doc/development/build-defaults.md)。
