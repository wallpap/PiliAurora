# PiliAurora v1.6.6

## 新功能

- 新增三款应用图标，可在设置中切换。Android 启动图标和 Windows 窗口、托盘图标会随选择更新。
- 空降助手支持按片段动作跳过或静音，手动处理时也可选择跳过。升级后保留已有分类设置，新增分类默认禁用。
- 账号凭证和 WebDAV 密码改为加密保存，升级时自动迁移本机旧明文凭证。仍可导入旧版明文备份；新版密文备份需要支持该格式的版本读取。详见[账号与设置备份](../guides/data-security.md)。

## 修复与改进

- 改进 Windows 窗口显示状态和视频中断恢复的处理。
- 修复弹幕点赞状态恢复和显示闪动的问题，调整弹幕通知的进度跳转位置。
- 修复私信确认已读后未读角标未清除的问题。
- 修复首页推荐刷新时，结果返回前刷新卡片消失的问题。
- 修复手动关闭空降助手片段提示后，仍在该片段内时提示再次出现的问题。
- 开启诊断记录时增加提示。

## 下载安装

Android 提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 安装包；Windows 提供 x64 安装程序和便携包。

Windows 安装版更新时，将安装程序指向原安装目录。便携版更新时，将 ZIP 完整解压到新目录，再启动其中的 `PiliAurora.exe`。账号和设置保存在 Windows 用户数据目录。

欢迎在 [GitHub Issues](https://github.com/wallpap/PiliAurora/issues) 反馈问题，并附上设备、系统版本和复现步骤。
