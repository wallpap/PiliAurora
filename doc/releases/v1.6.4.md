# PiliAurora v1.6.4

本版将 v1.6.3 预发布中的 Windows 更新流程改进转为正式版本，并继续修复播放器资源释放、窗口恢复和内容详情展示问题。远端发布包版本为 `1.6.4+457`。

## Windows 更新与窗口

- 改进覆盖安装：清理已退役的程序文件并保留用户文件；安装前检查程序文件占用，更新后的快捷方式使用一致的应用标识。
- 更新检查按正式版本号比较，跳过草稿和预发布；相同版本仅 build 后缀变化时不重复提示。
- 更新退出时保存主窗口和播放小窗状态，释放播放器资源后再退出；应用拒绝退出时安装器仍保留强制关闭能力。
- 修复 Windows 从最大化状态恢复后视频和弹幕视觉更新不再继续的问题。
- 完善 Windows 安装包内容检查、安装程序生成和升级流程验证。

## 播放器与下载

- 修复原生播放器打开失败、停止回执超时和快速切源时的资源释放，等待对应的卸载、结束和输出释放证据后再销毁运行时。
- 约束播放和暂停意图调用的等待预算，避免连续渲染阻塞卸载任务；关闭播放页面和退出应用时更可靠地完成清理。
- 下载队列删除当前任务组后自动继续下一个任务，并修复中断记录恢复、元数据替换和终态串行处理。

## 内容与消息

- 重整番剧详情和选集界面，补充分区内容、统计信息和相关剧集；分享时可正确解析主列表及分区中的当前剧集。
- 视频标签使用独立的专题和音乐样式，专题可直接打开话题页，音乐标签可打开音乐详情并复制名称。
- 统一视频和专栏消息卡片的展示，改善内容分享预览。

## 网络与隐私

- 统一 HTTP/1.1、HTTP/2 和回退请求的证书校验规则，WebDAV 仅允许 HTTPS 或按操作明确授权的本机回环地址。
- 收紧请求错误和通知输出中的敏感信息脱敏，并保持重复错误的脱敏结果稳定。

Android 提供 arm64-v8a、armeabi-v7a 和 x86_64 安装包；Windows 提供 x64 安装程序和便携包。
