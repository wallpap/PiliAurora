# PiliAurora v1.6.4

## 修复

- 修复 Windows 从最大化状态恢复后，视频和弹幕画面不再刷新的问题。

## Windows 更新

- 覆盖安装时清理已退役的程序文件，保留用户文件，并在安装前检查程序文件占用。
- 更新后的快捷方式使用统一的应用标识。
- 版本检查按正式版本号比较，跳过草稿和预发布版本；只有 build 后缀变化时不重复提示。
- 更新退出时保存主窗口和播放小窗状态，释放播放器资源后再退出。
- 增加安装包内容、安装程序和升级流程检查。

## 视频详情

- 专题标签和音乐标签使用独立样式。点击专题标签打开话题页，点击音乐标签打开音乐详情，长按音乐标签可以复制名称。

## 更新弹窗

- Windows 和 Android 按平台显示对应的下载选项。
- 操作按钮改为横向排列，移除安装路径、播放窗口和任务栏等使用说明。
- “此版本不再提醒”按发布版本记录，后续版本仍会自动检查。

Android 提供 arm64-v8a、armeabi-v7a 和 x86_64 安装包；Windows 提供 x64 安装程序和便携包。

完整变更：[v1.6.2...v1.6.4](https://github.com/wallpap/PiliAurora/compare/v1.6.2...v1.6.4)。
