# v1.0.13

- Android 新增“自动纹理缩放”实验设置，默认关闭。关闭时使用视频源尺寸；开启后按屏幕分辨率等比限制输出尺寸，并在下次加载视频时生效。
- Android 解码恢复补充 HardwareBuffer 映射错误处理，并覆盖 PTS 推进或不可用时持续取图异常。恢复过程仍检查暂停、缓冲、seek、EOF 和单媒体预算。
- 修复 WebP 转换取消或结束时的句柄销毁竞争；清理前等待事件循环退出。
- 移除 Android 每帧 JNI 查找和反射，恢复 Flutter 引擎帧通知。诊断属性改由事件缓存，减少同步读取。
- 调整跳转等待、切源时序、原生请求错误传递、倍速和播放器复用时的缓存更新。
- 解码器兼容性测试会检查视频输出和实际后端，区分原生兼容与回退后可播放，并显示播放进度。

持续错误恢复使用有界观察，当前原生库没有成功取图计数。真实画面、误回退率、画中画、旋转和设备性能仍需实机复测。
