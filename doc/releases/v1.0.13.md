# v1.0.13

- 新增 Android「自动纹理缩放（实验性功能）」设置，默认关闭；关闭时使用原生视频源尺寸处理，开启后按屏幕分辨率等比限幅，下次加载视频生效。
- 改进 Android 解码恢复，补充 HardwareBuffer 映射错误，处理 PTS 推进或不可用时的持续取图异常，保留暂停、缓冲、seek、EOF 和每媒体预算保护。
- 修复 WebP 转换取消及结束时的句柄销毁竞争，统一等待事件循环退出后清理。
- 移除 Android 每帧 JNI 查找和反射，恢复 Flutter 引擎帧通知；诊断属性改为事件缓存，减少同步读取。
- 改进跳转等待及切源时序、原生请求错误传递、倍速和播放器复用时的缓存更新。
- 解码器兼容性测试检查本视频输出与实际后端，区分兼容和回退后可播放，显示播放进度比。

持续错误恢复采用有界观察；现有原生库尚未提供成功取图计数。真实画面、误回退率、PiP/旋转和设备性能仍需实机复测。
