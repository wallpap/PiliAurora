# PiliAurora v1.6.9

## 播放与弹幕

- 调整弹幕优先级与渲染预算，在弹幕密集时优先展示相对权重较高的弹幕。

## 修复与改进

- 修复下载任务删除后队列可能停止、重复创建任务的问题。
- 修复专栏内容加载失败后无法重试的问题。
- 修复切换账号、刷新列表或关闭页面后，部分异步请求结果可能更新错误状态的问题。
- 改进搜索、关注列表、直播设置和隐私设置的状态管理。

## 下载安装

Android 提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 安装包；Windows 提供 x64 安装程序和便携包。

Windows 安装版更新时，将安装程序指向原安装目录。便携版更新时，将 ZIP 完整解压到新目录，再启动其中的 `PiliAurora.exe`。账号和设置保存在 Windows 用户数据目录。
