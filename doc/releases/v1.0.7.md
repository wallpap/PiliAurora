# PiliAurora v1.0.7

这个版本修正了 Android 自适应视频纹理在旋转时的状态和提交顺序，也整理了公共请求、设置备份及依赖维护代码。

## Android 视频输出

- 分离目标尺寸与成功提交尺寸，修正新视口使旧回调跳过 mpv 同步、导致纹理与输出几何不同步的时序缺陷。
- 源视频参数重建与视口适配共用原生提交队列，切源或销毁后不再提交旧媒体尺寸。
- 暂停期间保留现有纹理，由 Flutter 调整布局；恢复播放后提交最终视口目标。
- Android 自适应采用 250ms 尾沿稳定窗口，减少旋转过渡尺寸提交；单纯调整视口不再重复设置 `vo=gpu`。Windows 保留原 100ms 窗口。
- 补齐视口、纹理、目标/提交尺寸、缩放矩阵与原生几何诊断，补充 mpv 文件名中签名查询串的脱敏。

## 请求与设置备份

- 公共控制器统一管理请求生命周期。最后一次刷新才能写回结果，旧响应不会覆盖新数据或释放新请求的加载标记。
- 加载更多保持串行，异常后允许重试，列表处理不修改只读或固定长度响应。
- 设置恢复先校验两个分区，再只写入变化键；相同备份不产生存储写入或删除。
- WebDAV 同步从页面中移出，按操作创建和关闭客户端；备份内容在网络等待前取快照，下载完成后先关闭连接再恢复本地设置。

## 依赖与维护

- 发布版依赖精确固定，定制依赖继续使用仓库内版本化源码，不跟踪远端 Git 分支。
- 内化部分小型工具、诊断日志与设置 WebDAV 传输，保留依赖来源、许可与锁文件检查。
- 扩充公共请求、真实 Hive、回环 WebDAV、纹理提交和架构回归；发布支持先上传草稿、收齐双平台产物再公开。

## 验证范围与已知边界

- 本机全量 Flutter 测试 529 项通过，改动代码定向分析无诊断，依赖来源/锁定及工作流 YAML 检查通过。
- 公共请求、设置备份、WebDAV 同步和纹理提交回归已通过；Hive / WebDAV 往返使用独占临时目录和本机回环服务，不访问用户数据或外部账号。
- 尺寸同步及过渡提交的旧实现对照测试失败，新实现通过；测试使用受控原生通道；真实 Android GPU 的画面仍需实机验收。
- 用户设备上的暂停裁切、旋转闪屏是否完全消失仍需实机确认；250ms 稳定窗口不是系统动画完成事件。若仍异常，请在“关于 → 性能与诊断”开启记录并提供脱敏诊断包及异常时间。
- 设置恢复不是跨 Hive Box 原子事务；失败会传播，允许重试，失败前可能已经更新了部分值。
- 全目录分析仍有既有本地基准脚本和第三方诊断项，未通过关闭规则或隐藏告警掩盖它们。

正式附件包括 Android arm64-v8a / armeabi-v7a / x86_64 APK，以及 Windows x64 portable ZIP 和安装程序。
