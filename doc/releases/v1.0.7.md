# PiliAurora v1.0.7

本版修复 Android 自适应视频纹理在旋转时的状态与提交顺序，并调整公共请求、设置备份和依赖维护代码。

## Android 视频输出

- 分开记录目标尺寸和已提交尺寸，修复新视口到达后旧回调跳过 mpv 同步、造成纹理和输出几何不一致的问题。
- 源视频参数重建与视口适配共用原生提交队列，切源或销毁后不会再提交旧媒体尺寸。
- 暂停时保留当前纹理，由 Flutter 调整布局；恢复播放后再提交最终视口尺寸。
- Android 使用 250ms 尾沿稳定窗口，减少旋转过渡期间的尺寸提交；单独调整视口时不再重复设置 `vo=gpu`。Windows 继续使用 100ms 窗口。
- 增加视口、纹理、目标和提交尺寸、缩放矩阵及原生几何诊断，并对 mpv 文件名中的签名查询串脱敏。

## 请求与设置备份

- 公共控制器管理请求生命周期。只有最后一次刷新会写回结果；旧响应不会覆盖新数据，也不会清除新请求的加载状态。
- 加载更多请求按顺序执行，失败后可以重试；列表处理不会修改只读或固定长度响应。
- 恢复设置前先校验两个分区，再写入有变化的键。内容相同的备份不会触发存储写入或删除。
- WebDAV 同步逻辑移出页面。每次操作单独创建和关闭客户端；等待网络前先复制备份内容，下载后先关闭连接再恢复本地设置。

## 依赖与维护

- 发布版精确固定依赖版本，定制依赖使用仓库内的版本化源码，不跟踪远端 Git 分支。
- 将部分小型工具、诊断日志和设置 WebDAV 传输纳入仓库，并保留依赖来源、许可证与锁文件检查。
- 增加公共请求、真实 Hive、回环 WebDAV、纹理提交和架构回归。发布流程可先上传草稿，收齐 Android 与 Windows 附件后再公开。

## 验证范围与已知边界

- 本机全量 Flutter 测试 529 项通过；改动代码定向分析、依赖来源与锁定检查，以及工作流 YAML 检查均通过。
- 公共请求、设置备份、WebDAV 同步和纹理提交回归通过。Hive/WebDAV 往返使用专用临时目录和本机回环服务，不访问用户数据或外部账号。
- 旧实现的尺寸同步与过渡提交对照测试失败，新实现通过。测试使用受控原生通道；Android GPU 画面仍需实机验收。
- 暂停裁切和旋转闪屏是否已在用户设备上消失仍需实测。250ms 稳定窗口不等于系统动画完成事件；问题复现时，请在“关于 → 性能与诊断”启用记录，并提供脱敏诊断包和异常时间。
- 设置恢复不是跨 Hive Box 的原子事务。失败会向上抛出，允许重试；失败前可能已有部分值写入。
- 全目录分析仍有既存的本地基准脚本和第三方诊断项；本版没有关闭检查或隐藏这些告警。

正式附件包括 Android arm64-v8a / armeabi-v7a / x86_64 APK，以及 Windows x64 portable ZIP 和安装程序。
