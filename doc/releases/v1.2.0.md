# PiliAurora v1.2.0

本版为 Windows 播放增加独立窗口和音量控制，同时完善播放请求隔离，并改进 Android 发布包的 ABI 选择。

## Windows 播放

- 视频和直播可弹出多个独立播放窗口，支持拖动、调整大小、置顶，以及网格或层叠排列。
- 增加各窗口的音量调节、静音和声音来源切换；关闭并重新打开窗口时恢复其上次位置和大小。
- 播放器音量滑块支持滚轮、方向键和 `M` 键；播放窗口说明见[独立播放窗口文档](../guides/windows-playback-windows.md)。

## Android 与构建

- Android 发布构建可分别生成 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` APK。
- 构建脚本统一处理依赖解析与补丁应用；CI 补充诊断和播放回退检查。

## 播放和设置

- 视频和直播播放状态按页面归属和请求代次隔离，过期请求不会覆盖当前媒体状态。
- 网络读取中断时根据当前媒体和缓冲状态恢复播放。
- 将“清除缓存”入口移至“存储与应用”设置页，并整理设置与诊断页面结构。

发布附件和本版发布状态见 [GitHub Release](https://github.com/wallpap/PiliAurora/releases/tag/v1.2.0)。
