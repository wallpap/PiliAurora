# PiliAurora v1.6.5 预发布说明

本次更新包含自正式版 v1.6.2 以来的改动。预发布版本需要从 GitHub Releases 手动下载，应用内更新检查只提示正式版。

## 播放与弹幕

- 改进视频和直播的中断恢复，网络读取异常或播放提前结束时会根据当前状态尝试恢复；加载失败后可以手动重试。
- 修复关闭自动播放后预加载、点击播放意图及加载进度显示的问题。
- 修复视频播放结束后无法正常拖动进度或重播的问题。
- 修复番剧分享链接中的播放进度，以及选择 Akamai CDN 时可能使用错误签名的问题。
- 修复 Windows 最大化窗口恢复后视频和弹幕停止刷新的问题，并调整隐藏页面和图片资源的释放。

## 浏览与互动

- 首页推荐会根据屏幕可见范围继续加载内容，合作视频作者检查期间先显示其他卡片；加载失败时可以在列表末尾重试。
- 动态列表提前加载下一页，减少滚动到底部时的等待。
- 修复快速切换搜索词、刷新列表或切换账号时，旧请求结果覆盖当前内容的问题。
- 修复收藏或稍后再看列表中，异步操作完成后可能移除错误条目的问题。
- 修复消息未读状态被较早的查询结果覆盖，以及消息设置连续修改时状态不一致的问题。
- 改进扫码登录、短信登录和验证窗口的关闭处理。

## Windows 安装与更新

- 覆盖安装时检查程序文件是否占用，清理旧版本中不再使用的程序文件，并保留用户文件。更新退出时会保存播放窗口状态并释放播放器。
- 更新后的快捷方式使用统一的应用标识。更新提示按当前平台提供下载选项，“此版本不再提醒”只对选中的版本生效。
- 更新检查按正式版本号比较，跳过草稿和预发布版本；仅构建号变化不会重复提示。

## 下载安装

Android 提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 安装包；Windows 提供 x64 安装程序和便携包。安装版请安装到原目录；便携版请将压缩包完整解压到新目录。账号、设置和缓存会保留。

欢迎在 [GitHub Issues](https://github.com/wallpap/PiliAurora/issues) 反馈问题，并附上设备、系统版本和复现步骤。
